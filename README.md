# Проект "greenapi"

**Описание:**  
Веб-приложение на React для **получения и отправки текстовых сообщений в Telegram** с использованием каналов интеграции **Green API**.
Проект предоставляет интерфейс для авторизации по инстансу и обмена сообщениями в реальном времени.

---

### Стек и Окружение

- **Окружение:** Node.js `v24.21.0`+, npm `11.19.0`+
- **Стек:** React 19, TS 6, Vite 8, Tailwind 4.
- **Стейт / Сеть:** Zustand 5 (клиент), TanStack Query 5 (сервер), Axios.

---

### Локальный запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск dev-сервера (Vite)
npm run dev
```

---

### Скрипты сборки

```bash
npm run build    # Проверка типов (TSC) + Сборка в /dist
npm run preview  # Локальный запуск продакшн-билда
```
